# S2-MOM-v1 manuscript — number audit

Written 2026-10-07; revised the same day (tables and figures renumbered, derived numbers removed). Regenerated by `build_manuscript.py`; the full machine-readable table is `number_audit.csv` (one row per number filled from an artifact) and the check results are in `consistency_check_log.txt`.

## How the numbers get into the manuscript

The manuscript is not typed with result numbers in it. `manuscript.template.md` holds placeholders such as `{{K/H2d/primary/mean|+.4f}}`; the build script reads the registered result file, formats the value, writes `manuscript.md`, and logs the fill. A result number cannot therefore differ from its artifact through a typing error. The build stops if any registered file's SHA-256 differs from its registered value.

Source keys: `P` primary_results.json · `C` confirmation_results.json · `S` sensitivity_results.json · `B` blinded_precision.json · `E` step_e_results.json · `K` c2_results.json · `QP`/`QC` pre-run check files.
