## 2. Model

- **Segment:** a symbol with one ISIN, as NSE's own daily files show it. Before 2011-06-22, a symbol's presence splits into a new segment at any gap longer than 20 sessions, since nothing proves a returning symbol is the same security.
- **Links (evidence only):**

  | Link | Evidence |
  |---|---|
  | `ISIN_SAME` | The same ISIN under two symbols that never trade on the same day |
  | `SYMBOL_CHANGE` | NSE's symbol-change file, dates within 10 days, ISINs identical when both exist |
  | `ISIN_INTRO` | The same symbol on the last session without an ISIN field and on 2011-06-22 (a file-format change) |
  | `ISIN_CHANGE_CA` | The same symbol changes ISIN between adjacent sessions, **and** an NSE split/bonus/consolidation record lies within 10 days. The record may be filed under a symbol already proven to be the same entity |

- **Never used:** names, price continuity, look-alike symbols, price jumps, Yahoo data.
- **End status:**
  - `ACTIVE_AT_CUTOFF`;
  - `DELISTED_EVIDENCED`: one `delisted.csv` row per entity, assigned to the entity carrying that symbol whose last session is the latest on or before the delisting date;
  - `ENDED_UNEXPLAINED`.

## 6. ETF / fund units

- **Identified** by ISIN prefix **INF** (588 segments, 444 entities, e.g. ABSLBANETF, ABSLLIQUID). Classified, **never deleted** from the raw archive or panel.
- **Planned handling (2F, to be approved):** exclude `FUND_UNIT` entities from the equity research universe.
- **Before 2011-06-22:** a fund trading in EQ can be identified only if its entity links (ISIN_INTRO) to a later INF ISIN. Funds that ended before then remain `UNKNOWN_NO_ISIN`.

## 7. Limitation: records before June 2011

- **Available before 2011-06-22:** symbol, series, OHLC, last, prevclose, volume, value. **No ISIN, no trade count.**
- **Not invented:** no ISIN is invented. Pre-2011 identity is symbol-based within segments; across gaps over 20 sessions it is **unresolved**.
- **Scale:** 2,178 entities never carry an ISIN, and 1,892 pre-ISIN gap splits stay unlinked.
- **Implication for a point-in-time universe:**
  - before mid-2011, instrument type (equity vs fund) and identity across long gaps can't be verified;
  - a 2006–2011 universe would include `UNKNOWN_NO_ISIN` securities whose type is unproven;
  - the 2F rule must decide (with approval) whether to start the verified universe at 2011-06-22, or to accept and document the pre-2011 uncertainty.
