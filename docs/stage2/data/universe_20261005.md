# Stage 2 point-in-time equity universe — UNIV-1 (Phase 2F)

**Built:** 2026-10-05.
**Status:** universe only. No returns, no adjusted prices, no experiments. Not committed.
**Code:** `src/stage2/universe.py`. Tests: `tests/test_stage2_universe.py`.
**Dataset:** `data/stage2/universe/univ1_pit_universe.parquet` (SHA-256 `2abf457a06abf0e8a0b96c0b0ca0f75ccc07729c0166b1812d7af4646cba9c42`).
**Manifest:** `univ1_manifest.json`, recording parameters, source checksums, the identity-file hashes, code file hashes plus git HEAD, generation time, cutoff and stats.

## 1. Why the verified universe starts on 2011-06-22

- **ISIN is the official security identifier.** NSE's daily files publish it only from **2011-06-22**.
  - Before that date the files carry no ISIN and no trade count (`TOTALTRADES`).
  - So (a) a fund or ETF trading in the EQ series can't be told apart from a company unless it later links to an INF ISIN, and (b) a symbol that disappears and returns can't be shown to be the same security rather than a reused symbol. 2E left 1,892 such pre-2011 gaps unresolved and 2,178 entities with no ISIN at all.
- **What can be claimed about 2005-01-03 → 2011-06-21:** NSE published these EQ prices, values and volumes, and they are preserved unchanged in the raw archive and panel.
- **What cannot be claimed:** that a universe drawn from them is point-in-time verified for instrument type or for identity across gaps. They are **not** used to build UNIV-1.
- **The window is filled from verified data only.** Liquidity is measured on verified sessions (≥ 2011-06-22) only, so the **first selection date is 2011-09-30**: the first month-end whose full 63-session window is verified (the 63rd verified session is 2011-09-21).

## 2. Definition (UNIV-1)

| Element | Rule |
|---|---|
| Data | NSE CM bhavcopy EQ rows, 2011-06-22 → **2026-09-30** (research cutoff); nothing later is accepted (`build` raises) |
| Selection dates | Last market session of each calendar month, **2011-09-30 → 2026-09-30 (181 dates)**. Membership selected on t applies from the next session until the next selection date |
| Identity at t | 2E segments joined only by 2E evidence links **already effective on t**; a link takes effect on the first session of its later segment. Components are recomputed for every t. **`entity_id` = the entity's earliest segment**, so it never contains a later symbol or ISIN |
| Candidate | An entity with an EQ row on t. `symbol_at_selection`, `isin_at_selection` and `series` are taken from that day's row |
| Exclusions, in order | `NOT_TRADED_ON_SELECTION_DATE` (no EQ row on t: suspended, other series, ended) → `FUND_UNIT` (ISIN on t starts INF) → `NON_EQUITY_ISIN` (neither INE nor INF, e.g. IN9 partly paid) → `INSUFFICIENT_HISTORY` (fewer than **50 valid sessions** in the 63-session window) |
| Valid session | An EQ row with traded value > 0. Missing or zero value counts as not valid |
| Liquidity | **Median of daily traded value (₹) over the 63 market sessions ending on t**, inclusive. Sessions without a valid row count as **0** |
| Selection | Eligible entities ranked by liquidity descending; **ties broken by `entity_id` ascending**. **MEMBER if rank ≤ 200**, otherwise ELIGIBLE_NOT_SELECTED (all eligible ranks are kept, so other N can be reproduced) |
| Never used | Today's NIFTY 50 or any index list; current names; future delistings or relistings; future volume; future symbols or ISINs; Yahoo; prices or price jumps for identity |

**Cases:**

| Case | Handling |
|---|---|
| Fewer than 63 verified sessions exist | No selection date before 2011-09-30 |
| Newly listed | INSUFFICIENT_HISTORY until 50 valid sessions exist in the window (e.g. ZOMATO, listed 2021-07-23, first eligible 2021-10-29) |
| Trading suspension | Suspended sessions count as 0 and as not valid. Not traded on t means NOT_TRADED_ON_SELECTION_DATE; returning stocks need 50 valid sessions again |
| Missing traded value | Not valid; counts as 0 |
| Symbol change | Same entity from the change's effective session; `symbol_at_selection` shows the symbol of that day (ZOMATO before 2025-04-09, ETERNAL after; `entity_id` stays `ZOMATO\|…`) |
| ISIN change | Same entity only if 2E linked it (an NSE corporate-action record); otherwise a new entity (2E flag `ISIN_CHANGE_UNEXPLAINED`, 89 cases) |
| Relisting | The same ISIN returning means the same entity, which must re-qualify (4 member segments show such gaps: BCG, GVKPIL, RSSOFTWARE, UNITECH) |
| Later delisting | Never affects earlier dates. Members that later ended: 105 ENDED_UNEXPLAINED + 21 DELISTED_EVIDENCED (e.g. ALBK, ANDHRABANK, ABIRLANUVO, SATYAMCOMP 2011-09 → 2013-06), all retained |
| ETF / fund | Excluded whenever the ISIN on t starts INF (18,915 rows). Never deleted from raw data |

## 4. Checks on the real dataset

- **No members with a non-INE ISIN:** 0.
- **No point-in-time identity leak:** 0 rows whose `entity_id` or selected segment starts after the selection date.
- **Deterministic:** an identical content hash (`9842ddf9fd8a7893`) on rebuild.
- **Mutation check:** shifting the liquidity window one session into the future makes the point-in-time invariance test fail.

## 5. Parameters to confirm before any study uses UNIV-1

These were chosen ex ante; no strategy result was used.
- **N = 200.** All eligible ranks are stored, so other N can be reproduced.
- **MIN_VALID = 50 of 63** (about 80%).
- **Monthly rebalance.**
