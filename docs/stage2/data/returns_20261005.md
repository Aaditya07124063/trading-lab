## 1. Price series available for Stage 2

| Series | Status |
|---|---|
| **Raw NSE EQ prices** (open, high, low, close, last, prevclose, volume, value), 2011-06-22 → 2026-09-30 | Copied unchanged from the raw archive, with `source_sha256` per row. **Immutable** (tested) |
| **Raw close-to-close return** `ret_raw` | Always reported when a previous row of the same entity exists. Not adjusted |
| **Corporate-action-adjusted price return** `ret_adj` | Only on rows where an NSE bonus/split record **validates** under the 2D rule (CA-2); factor = 2D-parsed b/(a+b) or Y/X |
| **Research-grade daily price return** `ret_research` | = `ret_adj` (validated adjustment) or `ret_raw` (no event), on research-grade rows only; NaN elsewhere |
| Adjusted price *levels* | **Not provided.** They would chain across unresolved discontinuities. Build them only by compounding `ret_research` within clean spans |
| **Total return (dividends)** | **Not available.** See §4 |
| Yahoo data / adjustments | **Not used anywhere** (tested) |

## 2. Rules (RET-1)

- **Scope:** the UNIV-1 verified period, EQ rows only. Rows after 2026-09-30 are refused; rows before 2011-06-22 are excluded.
- **Entity:** 2E segments joined by 2E evidence links; `entity_id` = earliest segment (as in UNIV-1). Join with UNIV-1 through `segment_id`. Returns continue across evidenced symbol or ISIN changes (`identity_transition`; 934 rows).
- **Events on a row:** NSE records filed under **any symbol of the entity** with `prev_date < ex_date ≤ date`. This is how records filed under a later symbol are caught; for example TATAMOTORS's 2025-10-14 demerger is filed under TMPV.
- **Status,** first rule that applies:

  | Order | Status | Condition |
  |---|---|---|
  | 1 | `FIRST_OBSERVATION` | No previous row (new listing, start of the period, or a new entity after an unexplained ISIN change) |
  | 2 | `MISSING_PRICE` | Close is missing or not positive |
  | 3 | `MULTI_SESSION_GAP` | The previous row is not the previous market session (suspension, other series, relisting) |
  | 4 | `EVENT_DISCREPANT` | A bonus/split record whose price check doesn't validate |
  | 5 | `EVENT_INCONCLUSIVE` | A bonus/split too small to verify in prices |
  | 6 | `EVENT_UNADJUSTABLE` | Rights, scheme/demerger/amalgamation/capital reduction, consolidation, unparsed or non-equity bonus/split |
  | 7 | `UNEXPLAINED_JUMP` | The (adjusted-if-validated) ratio is beyond 1.4× either way |
  | 8 | `ADJUSTED_VALIDATED` | A validated bonus/split, adjustment applied (**research-grade**) |
  | 9 | `OK` | None of the above (**research-grade**) |

- **Never done:** adjusting without a validated NSE record; inferring an event from a price move; repairing a discontinuity. Each of these is flagged instead (tests include a mutation check: applying factors without validation makes the tests fail).
- **Delistings:** the series simply ends at the last NSE row. History is kept; no terminal return is assumed (a delisting return is unknown and is a documented limitation).
- **Relistings:** the first return after the gap is `MULTI_SESSION_GAP`.

## 3. Results on the real data (2011-06-22 → 2026-09-30)

- **Coverage:** 6,115,762 entity-days; 3,683 entities; 3,768 sessions.
- **Research-grade rows: 6,069,518 (99.24%)** = OK 6,068,693 + ADJUSTED_VALIDATED 825.
- **Not research-grade:**
  - MULTI_SESSION_GAP 41,283;
  - FIRST_OBSERVATION 3,683;
  - UNEXPLAINED_JUMP 914;
  - EVENT_UNADJUSTABLE 316 (rights 310 and schemes/demergers 161 among the flags);
  - EVENT_INCONCLUSIVE 44;
  - EVENT_DISCREPANT 4.
- **Unresolved discontinuities:** 1,278 rows across **384 entities**.
- **Research-grade share by year:** 97.0–99.8% (lowest in 2013, highest in 2022).
- **Validated adjustments:** all known events, e.g. RELIANCE 2017-09-07 and 2024-10-28, HDFCBANK 2019-09-19 and 2025-08-26, TCS 2018-05-31, INFY 2018-09-04. Raw −49% to −50% becomes −0.9% to +2.8%.
- **UNIV-1 interaction:**
  - Of 738,765 return rows inside members' holding periods, **129 (0.017%) are not research-grade**, across 93 entities (unadjustable 69, unexplained jump 42, gap 11, inconclusive 7).
  - **125 of 687 member entities** have at least one unresolved discontinuity somewhere in 2011–2026 (listed in `ret1_member_entities_with_unresolved_discontinuities.csv`).

## 4. Limitations

1. **NSE corporate-action records are incomplete** (2D: e.g. HEG 2024 and TIPSINDLTD 2023 have no records). **A universally reliable adjusted historical price series, or a total-return series, cannot currently be claimed.** Adjusted returns are trustworthy only where an event validates. Every other discontinuity is exposed through flags.
2. **Dividends are not included:** 19,310 ex-dividend rows are flagged (`dividend_exdate`).
   - Returns are **price returns**, which understate total return by the dividend yield.
   - Dividend records exist (2006+), but amounts are often stated as a % of a face value we haven't verified historically, so no total return is built.
3. **Not adjusted:** rights issues, demergers and schemes, capital reductions and consolidations. No defensible factor has been established, so they are flagged and not research-grade.
4. **Unexplained jumps (914)** may be genuine market moves or unrecorded events. They are not distinguished, and stay non-research-grade.
5. **No delisting return:** returns stop at the last NSE row.

## 5. What return studies must exclude (rules for future protocols, not decisions)

- **Daily-return studies:** use `ret_research` only (research-grade rows). Non-research-grade days are missing, never filled.
- **Studies needing continuous price paths** (lookback returns, rolling highs, volatility windows): exclude any entity-window containing an unresolved discontinuity (the list above), or truncate at it. The choice must be pre-registered per study.
- **Any total-return or income claim:** not supported under RET-1.
